### International standards: agent URI scheme and verifiable agent identity (draft-04)

- [The agent URI Scheme and Verifiable Agent Identity, revision 04](https://datatracker.ietf.org/doc/html/draft-narvaneni-agent-uri-04), by independent authors Yaswanth Narvaneni and Sai Purnima Ravi, published through IETF Datatracker on 20 October 2026 (primary technical proposal; publication hour not verified, so ordering against the previous cutoff is uncertain) (source: 2026-10-21-ai-agent-identity-news.md).
- The draft defines a stable agent URI that maps to an identity document served over HTTPS, connects agent keys to a web origin or decentralized identifier, and signs references to protocol metadata. Further profiles cover signed HTTP requests and short-lived agent instances using WIMSE workload credentials. It separates proof of key control from claims about the operator and from authorization to act (source: 2026-10-21-ai-agent-identity-news.md).
- It is an **individual Internet-Draft, not an adopted or endorsed IETF standard**. Added to [[agent-standards-and-interoperability]].
